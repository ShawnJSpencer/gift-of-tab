# The Gift of Tab 🎸

A personal app for creating, importing, practising and performing guitar, ukulele and piano-chord tabs. Built for iPad first, works on iPhone.

- **Create** tabs with chord boxes above each beat (pick a chord → the tab fills in → edit any note), techniques (h p / \ b r ~ x, ghost, harmonic, PM), lyrics rows, chords-and-lyrics blocks and section labels.
- **Import** by pasting text from any tab site (chords over lyrics, ASCII tab, ChordPro).
- **Playlists** for practice and the stage — swipe between songs, auto-scroll, stage (dark) mode, transpose, chord diagrams.
- **Practice tracker** — daily goal (default 30 min), streak counter, calendar, concert countdown and an emoji party when you hit your goal.
- **Sync** between devices through a private GitHub Gist (Sync & settings in the menu). Works offline.

Plain HTML/CSS/JS — no build step. Hosted with GitHub Pages.
